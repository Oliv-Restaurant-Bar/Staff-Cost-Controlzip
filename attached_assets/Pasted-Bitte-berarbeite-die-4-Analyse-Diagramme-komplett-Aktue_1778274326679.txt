GRUNDSATZ

Weniger technische Darstellung.
Mehr Management-Dashboard.
Weniger Linienchaos.
Weniger Farben.
Mehr Fokus auf Aussage.

Die wichtigste Frage muss sofort beantwortet werden:
- Ist der Monat gut oder schlecht?
- Sind die Kosten unter Kontrolle?
- Wie entwickelt sich die Quote?
- Welche Monate sind kritisch?

1. PERSONALKOSTENQUOTE PRO MONAT NEU AUFBAUEN

Aktuell:
- Linien + Balken + Ziel + Farben = zu chaotisch

Neu:
Nur EIN Balken pro Monat.

Der Balken zeigt:
PK Quote Ist %

Farblogik:
- Grün = unter Ziel
- Orange = nahe Ziel
- Rot = über Ziel

Zusätzlich:
- Zielwert als dünne horizontale Linie
- Prozentwert direkt IM oder ÜBER dem Balken
- Monat klar lesbar

Beispiel:
Jan → 40.4 %
Feb → 40.7 %
Mär → 34.4 %
Apr → 32.0 %

Keine zweite Linie mehr.
Keine doppelte PK Plan Linie.
Keine unnötige Legende.

Optional:
Beim Hover Tooltip:
- PK Ist CHF
- Umsatz CHF
- PK Quote %
- Zielwert %

2. UMSATZ VS. PERSONALKOSTEN NEU

Aktuell:
Zu kleine Balken.
Zu viele Informationen gleichzeitig.
Prozent kaum lesbar.

Neu:
Kombinierte Management-Darstellung.

Pro Monat:
- Umsatz Balken (gross)
- Personalkosten Balken (kleiner davor oder daneben)

Direkt auf dem Personalkosten-Balken:
PK Quote %

Beispiel:
Apr:
Umsatz CHF 267k
PK CHF 96k
36.1 %

Wichtig:
- Prozentwert gross genug
- CHF Werte im Tooltip
- Keine unnötigen Farben

Farben:
Umsatz = neutral blau
PK = orange/rot

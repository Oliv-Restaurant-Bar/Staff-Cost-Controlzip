Erweitere das Modul "Personalbedarf-Abgleich" um eine präzisere und operativ sinnvollere Warnlogik.

Ziel:
Bereits eine Abweichung von 1 Person soll sichtbar werden. In der Gastronomie kann bereits eine einzige Person zu viel oder zu wenig erhebliche Auswirkungen auf Personalkosten oder Servicequalität haben.

WICHTIG:
Es handelt sich ausschliesslich um eine Anpassung der Anzeige- und Warnlogik.
Keine Änderungen an der eigentlichen Berechnung des Personalbedarfs.

──────────────────────────────
1. Neue Warnlogik
──────────────────────────────

Für jede Kombination aus:

• Datum
• Bereich (Service/Küche)
• Schicht (Mittag/Abend, falls vorhanden)

berechnen:

Geplant
Benötigt
Differenz

Anzeige:

Differenz = 0

→ Grün
→ "Optimal"

Differenz > 0

→ Rot

Differenz < 0

→ Rot
→ "Unterbesetzt"

Bereits -1 Person muss rot dargestellt werden.

Die bisherige Gelb-/Toleranzlogik vollständig entfernen.

====================================================
1. AUTO-REFRESH / RELOAD LOOP BEHEBEN
====================================================

Bitte StaffSchedulePage prüfen:

- keine setInterval Reloads
- keine useEffect-Endlosschleifen
- keine window.location.reload()
- keine wiederholten Supabase Reads alle paar Sekunden
- keine dependency loops in useEffect
- kein ständiges setState beim Laden

Die öffentliche Seite soll:
- einmal laden
- Payload anzeigen
- stabil bleiben

Optional:
Button "Aktualisieren" manuell anzeigen.

====================================================
2. ROBUSTES LOADING
====================================================

Beim Öffnen:

1. Loading anzeigen
2. Supabase einmal lesen
3. Erfolgreich → Plan anzeigen
4. Fehler → stabile Fehlerkarte mit "Erneut versuchen"

Kein automatisches Endlos-Neuladen.

====================================================
3. MOBILE EXPORT FÜR MITARBEITER
====================================================

Im geteilten Dienstplan-Link bitte Button ergänzen:

"Plan exportieren"

Auf Mobile gut sichtbar, aber nicht störend.

Export-Optionen:
- PDF herunterladen
- Als Bild / Screenshot vorbereiten optional
- Drucken / Teilen über Browser Share API wenn möglich

Für Teamlink:
Exportiert aktuelle Ansicht:
- alle Mitarbeiter oder gefilterter Mitarbeiter
- aktuelle Woche
- keine Kosten
- keine Löhne
- keine internen Warnungen

Für ausgewählten Mitarbeiter:
Wenn Dropdown auf einem Mitarbeiter steht:
Export nur diesen Mitarbeiter.

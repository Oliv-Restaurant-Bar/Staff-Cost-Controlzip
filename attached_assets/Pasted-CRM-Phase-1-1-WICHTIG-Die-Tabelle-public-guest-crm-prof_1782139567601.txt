* VIP manuell

* Speichern

Verhalten:

* Speichern speichert alle Felder in die Datenbank
* Änderungen verwerfen setzt das Formular auf den letzten gespeicherten Stand zurück
* Keine separaten Speichern-Buttons pro Feld

3. Erstes Speichern

Wenn für einen Gast noch kein Datensatz in guest_crm_profiles existiert:

* leeres Formular anzeigen
* beim ersten Speichern automatisch Datensatz erstellen
* danach normale Updates verwenden

4. VIP / Stammgast Anzeige

Manueller VIP:

* Wenn vip_manual = true → VIP Badge anzeigen
* Unabhängig vom automatisch berechneten Segment

Manueller Stammgast:

* Wenn stammgast_manual = true → Stammgast Badge anzeigen
* Unabhängig vom automatisch berechneten Segment

Automatische Segmente dürfen bestehen bleiben.

3. HARDCODED TEST PAYLOAD
====================================================

Zum Test bitte zuerst sogar OHNE echten Dienstplan-Payload speichern.

Nur:

const token = crypto.randomUUID()

const payload = {
  token,
  type: "test",
  restaurant: "oliv",
  title: "Test Dienstplan",
  createdAt: new Date().toISOString()
}

Dann:

await supabase.from("app_settings").upsert({
  key: `published-schedule:${token}`,
  value: payload
})

Wenn erfolgreich:
- Link anzeigen
- toast "Test-Link erstellt"
- console.log payload

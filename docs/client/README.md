# Pre-existing docs (predate this engagement)

Everything in this folder predates the current bug-fix/audit engagement — KPI and navigation
inventories, per-feature walkthroughs. They're kept as-is here, not something this engagement's
work gets filed into.

Docs generated during this engagement (issue tracker, changelog, missing-tables investigation,
onboarding `Overview.md`, the client-facing status summary) live in `docs/dev/` instead, even
when their content is meant for the client to read — the split is by who/when generated it, not
by audience.

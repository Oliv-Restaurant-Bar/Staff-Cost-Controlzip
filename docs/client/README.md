# Client-facing docs

Everything in this folder is written to be shared with the client directly — plain language,
no file paths or code internals. Internal engineering tracking (issue lists with code
references, dated technical changelogs, migration/table investigations) lives in `docs/dev/`
instead and is not meant to go to the client as-is.

When a new client update is written, add it here (or update `personal-cost-tracker-summary.md`
in place) rather than mixing it into the `docs/dev/` files.
